# CodexU 0.6.3

恢复 0.6.0 的界面与功能，并保留 0.6.2 的模型补充和修复。

- 恢复顶部额度、Token 和金额概览，以及用量趋势、项目排行、Skill 使用、双运行时、设置与诊断五个页面。
- 恢复完整悬浮条、额度已用／剩余切换、可选今日 Token 和桌面副本。
- 保留最新六个模型的补充、37 行历史费率目录和 Sonnet 5 价格修正。
- 保留 `Redirect was cancelled` 自动更新修复，以及历史留存、统计核算、导出、隐私和退出协调修复。
- 保留历史清理操作和已有数据、设置。已被旧版本覆盖保存的桌面、今日 Token 或额度模式偏好，可在恢复的设置页重新调整。

v0.6.2 可正常自动更新。**v0.6.0／v0.6.1 若自动下载失败，请手动升级一次**：从 [0.6.3 发布页](https://github.com/yuweiyang9611/CodexHelperProject/releases/tag/v0.6.3) 下载安装包，退出应用后覆盖安装。便携版请解压完整 ZIP。

本地后端、前端、Electron、真实桌面集成和更新网络回归通过；主要页面匹配 v0.6.0 原始截图。专用 Windows 10/11 多屏、混合 DPI、Win+D 与 Explorer 验收仍待后续。详细范围和验证见 [界面恢复记录](ui-restoration-0.6.3.md)。
