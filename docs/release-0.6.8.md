# CodexU 0.6.8

新增可选的 Claude 后台额度读取：开启后由官方 Claude Code CLI 随刷新读取额度百分比和真实重置时间，不必再到 Desktop 会话中手动查询。

- 「设置与诊断 → 数据源」显示 Claude CLI 登录状态，包括是否已登录、认证方式和检测到的 CLI 来源（独立安装、PATH 或 Desktop 内嵌），可随时重新检查。检测只运行 `auth status`，不打开浏览器，也不发起模型请求。
- 新增「通过 Claude CLI 在后台读取额度」，默认关闭。开启后，每次刷新由 CLI 使用自身登录读取五小时与七天额度及重置时间，至多每 2 分钟一次。查询只发送一条 `get_usage` 控制请求，不发送提示词、不调用模型、不读取凭据。查询失败或 CLI 未登录订阅账号时会逐步延长重试间隔，并在概览中说明原因。
- CLI 读取的额度与终端 statusLine 快照一样参与额度提醒、耗尽预测和顶部状态条。若已绑定的 Desktop 会话有更新的查询结果，则优先显示该结果。
- 运行时升级到 .NET 11，并更新 Electron 及前端构建依赖。

CLI 需要单独登录，并应选择与 Claude Desktop 相同的账号。登录方法、查询方式和数据范围见 [CLI 使用说明](claude-cli-usage.md)。

安装版可在应用内检查更新；便携版请解压完整 ZIP。
