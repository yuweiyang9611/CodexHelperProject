# CodexU 0.6.11

本版将 Antigravity 纳入三运行时，改进后台额度查询和价值估算，并更新费率目录与启动恢复机制。

- Antigravity 成为第三个运行时。可在顶部切换到 Antigravity，通过额度环查看各模型组的剩余额度和重置时间。「双运行时」更名为「三运行时」，新增 Antigravity 栏。仅在 Antigravity 额度可见时定时查询，点击顶部刷新按钮可立即查询。
- 如果 `agy` 将 `/usage` 当作普通提问并调用模型，应用会暂停对该 CLI 版本的额度查询。重启后仍保持暂停，升级 `agy` 后自动恢复。单个异常分组不会影响其他分组的额度显示。
- 为避免用量接口限流，Claude CLI 后台额度查询至少间隔 5 分钟，失败后依次等待 5、10、20、30 分钟再试。查询状态保存到磁盘，重启后按已保存的时间安排查询。设置页「Claude Code CLI」卡片会显示上次查询结果和下次查询时间。
- 展开概览中的「价值估算」，可查看本月缺少费率的模型及其 Token 数。可在「设置与诊断 → 价格与费率」添加自定义价格。
- 费率目录更新至 2026.11.2，新增 GPT-6.2 Astra 和 GPT-6.2 Sol（11 月 17 日起），以及 Claude Fable 5.2 和 Claude Mythos 5.2（11 月 9 日起）。Codex 自动审查（`codex-auto-review`）按 0 计价。详见 [2026-11-27 费率更新](update-2026-11-27.md)。
- 启动时界面进程偶发崩溃会自动重试加载，例如部分安全软件干扰 Chromium 沙箱时。修复了顶部状态条窗口关闭后的异常，外部命令输出超限时会立即结束进程。
- 仓库已移除旧 WPF 宿主，安装包仍支持从 v0.5.0 原位升级。

安装版可在应用内检查更新；便携版请解压完整 ZIP。
