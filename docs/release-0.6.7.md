# CodexU 0.6.7

完善 Claude Desktop 额度会话的设置体验，统一费用核算、订阅月费和项目排行的显示。

- Claude Desktop 额度会话支持选择文件和保存前验证，区分缺少查询结果、结果过期、文件过大及读取失败。过期的额度卡片提供复制查询指令和上次查询时间，文件过大时提示绑定新的专用会话。
- 概览与双运行时页面正确显示手动订阅月费。自动模式无法确定套餐价格时显示未知；明确选择手动月费后，费用对比采用保存的金额。
- 重置倒计时随本地时钟更新，并显示具体重置时刻。窗口回到前台时立即校正，到点后显示“已到重置时间，等待新快照”。
- 概览、用量明细和导出共用计价记录。缺少模型费率或必要 Token 分项的记录保留 Token，并显示未核算原因；同一天的完整记录继续计价。旧版整日估值单独保留，避免与恢复的明细重复相加。
- 项目榜区分已核算为零、部分核算和金额未知，部分金额以 `≥` 标注。概览、趋势、热力图和桌面小窗使用同一套美元换算；缓存节省额单独展示。已核算金额达到订阅月费时确认回本，其余部分核算场景保持待定。
- 双运行时汇总、费率草稿预览、Claude 额度状态及项目成本排行统一由 .NET 后端计算。读取失败的运行时会明确标出；编辑费率时采用与正式保存及计价相同的模型别名、生效日期和覆盖规则。
- 更新 Electron 及相关依赖，完善第三方清单检查的差异附件，方便维护依赖升级。

Claude Desktop 额度继续按需更新。在绑定的 Code 会话中调用 `get_usage` 后，codexU 刷新即可读取新结果；查询工具本身可能缓存最多 60 秒。订阅月费可在设置中填写实际金额。接入范围和数据有效期见 [Claude Desktop 接入说明](claude-desktop-usage.md)。

安装版可在应用内检查更新；便携版请解压完整 ZIP。
