# CodexU 0.6.5

修复 Claude Desktop Code 的额度来源和订阅费用显示，明确区分历史采样、自动参考价与手动金额。

- 自动读取 Desktop 专用本地用量历史，显示可确认的 5 小时／7 天已用百分比和采样时间，并标注非实时。缺失的窗口继续显示未知，不从旧样本补齐。
- 历史不提供重置时间和套餐档位，不据采样时间、百分比或模型名称推算这些数据。超过 30 分钟、异常时间、格式不兼容或包含多个组织的历史不会用于显示；已有 statusLine 快照继续可用。
- Desktop 历史与 statusLine 按采样时间整份选择，隔离预测和通知，避免把采样变化当作额度重置或耗尽依据。
- 支持明确的 Claude Ultra 官方参考月费；旧 `max` 标签可能对应不同档位，信息不足时保持未知，不猜订阅价格。参考价不代表含税、折扣或渠道调整后的实际账单。
- 关闭自动识别后，设置中的手动月费在主概览和双运行时视图同时生效，并明确标注手动来源。

Desktop 历史文件属于观察到的本地缓存格式，不是公开稳定接口；格式或账号状态不明确时保守回退。此接入不把 Desktop 的所有聊天或云端 Cowork 用量纳入本地 Code Token 统计。

安装版可通过应用更新升级；便携版请使用完整 ZIP。
