# v0.6.3 界面与功能恢复

日期：2026-10-05。用户要求恢复 v0.6.0 的界面和功能，同时保留 v0.6.2 的模型补充与修复。

## 恢复范围

- 顶部额度、Token 和金额概览，以及用量趋势、项目排行、Skill 使用、双运行时、设置与诊断五个页面。
- v0.6.0 的走势、构成、分布、活跃日历、任务生命周期、月末预测、紧凑布局与深浅主题。
- 完整悬浮条：额度已用／剩余切换、可选今日 Token、近 7 天和累计 Token、金额，以及折叠、预览、锁定和位置恢复。
- 可选桌面副本、Windows 宿主能力、主题、透明度和位置设置。桌面副本仍默认关闭。
- 新配置采用 v0.6.0 的耗尽预测、费率覆盖阈值和今日 Token 默认值；明确保存的关闭或 0 值继续保留。

主页面、概览、双运行时、用量趋势和样式以 v0.6.0 原文件为基线。设置页保留历史清理操作、当前模型和费率目录，以及符合当前全部历史导出的说明；状态条保留刷新时间元数据。

## 保留的补充与修复

- 费率目录 `2026.10.1` 的 37 行历史费率，含 GPT-6.1 Sol、GPT-Rosalind-Research、Claude Fable／Mythos 5.1、Opus／Sonnet 5.5，以及 Sonnet 5 已取消涨价的修正。详见 [模型与费率记录](rate-catalog-2026-10-05.md)。
- v0.6.2 的 GitHub 下载重定向适配器、源白名单、流式下载、取消和 SHA-256 校验，以及真实 Electron 网络回归。详见 [更新修复](updater-redirect-fix.md)。
- 日志解析、历史账本、去重、Token 分项可用性、日期费率、通知核算、查询缓存及筛选导出接口。
- 全部历史 JSON schema 2／CSV 导出、备份恢复、历史清理、隐私脱敏、IPC 白名单、退出协调和依赖安全修复。

恢复后的主界面采用 v0.6.0 的页面与统计范围。后端组合筛选和 JSON schema 3 导出接口继续保留，但不把后续改造的页面导航加入恢复界面。

## 升级与设置

版本按最小补丁号递增为 0.6.3。v0.6.2 可通过已修复的自动更新链路升级；v0.6.0／v0.6.1 若仍出现 `Redirect was cancelled`，需从发布页手动下载安装包一次。

升级保留已有设置和用量数据。若 v0.6.1／v0.6.2 已将桌面开关、今日 Token 或额度模式覆盖并保存，程序无法判断原来的选择；可在恢复的设置页重新开启或切换。不会猜测并覆盖明确保存的偏好。
