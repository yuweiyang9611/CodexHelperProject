# CodexU 0.6.12

本版修复 0.6.11 交叉审查发现的问题，重点是后台额度查询的防护和限流，以及 Antigravity 模式下的界面问题。

- Antigravity 额度查询更稳妥。`/usage` 必须明确报告没有调用模型，才算安全完成；输出过长、乱码、超时等无法确认的情况，会让该 CLI 版本依次暂停 30 分钟、2 小时、6 小时和 24 小时，重启后仍有效。应用最多记住 8 个曾调用模型的版本，切回旧版本也不会再查询。版本检查和额度查询各有独立的时间限制。
- Claude CLI 后台额度的限流不会被意外解除：状态文件暂时被占用时不会提前查询；查询开始前先保存下次查询时间，应用在查询中途退出也不影响；意外错误不再导致后续查询一直失败。
- 退出登录或找不到 CLI 后，不再在新账号读取失败时显示上一个账号的额度。设置页仍会显示上次成功读取的时间。
- 使用 API 密钥或第三方服务登录 CLI 时，打开设置页不再反复触发后台查询。
- 选择 Antigravity 时，保存设置、安装更新等操作失败会正常显示错误提示。
- 紧凑模式下点击设置按钮，会先退出紧凑模式再打开「设置与诊断」。
- 启动恢复失败时的提示框不再依附于尚未显示的窗口，能在任务栏中找到。

安装版可在应用内检查更新；便携版请解压完整 ZIP。
