# CodexU 0.6.6

接入 Claude Desktop Code 内建 `get_usage` 的原生查询结果，显示实际返回的额度百分比、重置倒计时和读取时间。

- 在设置的数据源高级选项中，可绑定已验证的单个 Desktop 会话文件。仅配对原生工具调用与结果，不解析助手转述，也不从模型专属周额度猜总额度。
- 采用查询结果中的真实重置时间，缺失窗口保持未知；完整快照选择避免混合不同来源。超过 15 分钟、异常时间、错配会话或无效内容会被拒绝，并明确说明回退来源。
- 主概览、双运行时及悬浮条区分查询快照和历史采样。未确认稳定账号范围前，查询快照不参与额度预测、通知或窗口去重。
- 保留手动订阅月费设置；新增绑定不会覆盖手动金额。

这是按需查询结果接入：需要在绑定的 Claude Desktop Code 会话再次调用 `get_usage`，codexU 刷新后读取新结果。应用不会自动给 Claude 发送消息或启动额外模型轮询。Desktop 工具本身可能缓存最多 60 秒。
