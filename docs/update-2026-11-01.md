## 本地兼容性与验证

本机样本确认 Codex `0.166.0-alpha.5.1` 的 `token_usage_record` 和旧 `token_count` 会双写；已统一使用线程累计计数，兼顾只有新事件的尾部和双写去重。Claude Code `2.1.309` 的同一回复可能按 content block 重复记录完整 usage；现在按 `message.id` 合并用量，同时保留工具统计和更完整的缓存明细。

索引升级触发原日志重解析；旧账本仅在核对原始观测后迁移，保留截断、改写和冲突保护。原始 Claude 日志已删除且账本没有消息 ID 时，不能可靠校正旧重复量，会保留原值并显示诊断。具体版本、数据布局、迁移条件和回归场景见 [本地兼容核对](runtime-compatibility-2026-11-01.md)。

构建使用仓库锁定的 .NET SDK 10.0.400 和 Node.js 22.23.2；未更换全局工具链，未修改 Codex 或 Claude 的原始日志、登录信息或应用设置。首次完整构建发现本机缺少原已锁定的 WebView2 包，执行 App 项目 `restore --force` 恢复原版本后，严格构建通过。
