# CodexU 0.6.9

Claude 后台额度读取改为默认开启：只要本机 Claude Code CLI 已登录订阅账号，升级后无需任何设置，刷新时就会显示 Claude 额度百分比和真实重置时间。

- 「通过 Claude CLI 在后台读取额度」默认开启。0.6.8 会把当时默认的“关闭”随设置一并保存，升级时这些旧值统一改为开启；之后在设置中手动关闭的选择会被保留，备份恢复也一样。
- CLI 未登录订阅账号时（包括未登录、使用 API 密钥或第三方服务），改为每小时重试一次，不再频繁启动 CLI。完成登录后，在「设置与诊断 → 数据源」点击「重新检查登录状态」即可立即恢复查询。
- 未找到 CLI 或 CLI 未登录时，概览不再提示，相关信息集中显示在设置中的 CLI 登录状态里；只有查询本身失败时，概览才会说明。
- CLI 未登录或已找不到时，不再沿用此前读取的额度。

开启后，应用会在刷新时启动官方 CLI，至多每 2 分钟一次。查询只发送一条 `get_usage` 控制请求，不发送提示词、不调用模型、不读取凭据；CLI 自身会访问 Anthropic 服务读取额度。CLI 已登录时，Claude 额度会参与额度提醒、耗尽预测和顶部状态条。不需要时，可在设置中关闭。详见 [CLI 使用说明](claude-cli-usage.md)。

安装版可在应用内检查更新；便携版请解压完整 ZIP。
