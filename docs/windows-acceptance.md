# Windows 原生验收矩阵

更新：2026-09-27。适用当前 Electron 主窗口、托盘和额度悬浮条。完整桌面副本已退役，不再测试 Explorer 附着；WPF 仅保留兼容与构建验证。

本轮已由用户确认以代码与自动化验证为准，以下专用环境验收留待后续，不作为本轮完成的前置条件。

使用专用 Windows 10 22H2 / Windows 11 环境和一次性用户。记录应用提交、系统版本、安装方式、显示器数量、各屏 DPI 和工作区坐标。所有数据使用临时合成日志，恢复与清理不得指向真实用户历史。

| 场景 | 操作与验收要求 | 当前证据 |
| --- | --- | --- |
| 安装、升级、卸载 | 运行 `tools/Test-ElectronInstaller.ps1`；旧 WPF 同 AppId 原位升级，安装后启动正常，卸载保留用户数据 | 已有 CI 流程；本轮未重跑安装矩阵 |
| 首次启动和重启 | 两系统分别启动、关闭到托盘、托盘退出后重开；主窗口、设置和状态条位置可恢复 | 本轮真实 Electron 合成数据测试；不能替代两系统矩阵 |
| Win+D | 打开主窗口与状态条，反复显示桌面，再用托盘及快捷键找回；不得抢焦点或出现不可找回窗口 | 待专用环境验收 |
| Explorer 重启 | 仅在测试环境重启 Explorer；确认托盘可访问、窗口可找回、退出无残留进程 | 待专用环境验收 |
| 混合 DPI 与负坐标 | 将窗口及状态条在 100%／150%／200% 显示器之间拖动，覆盖位于主屏左侧的负坐标屏幕；控件可操作，无越界 | 浏览器缩放与布局单元测试不构成原生验收；待测 |
| 移除显示器 | 在副屏放置主窗口和状态条后断开副屏；找回位置、重启，再连接副屏；窗口始终能回到可见工作区 | 待专用环境验收 |
| 后端与界面恢复 | 用 `node src/CodexU.Electron/scripts/test-desktop.cjs` 在临时数据目录中验证 Sidecar／renderer 崩溃恢复、历史留存、真实导出和备份恢复 | 本轮结果见完善记录 |

每次人工验收保存操作前后截图、脱敏诊断包和通过／失败原因。失败项记录复现步骤和环境，不以自动化通过或“未复现”替代完成。
