# Windows 原生验收矩阵

更新：2026-10-05。适用恢复 0.6.0 界面后的 Electron 主窗口、托盘、完整状态条与可选桌面仪表盘副本。保留后续模型、历史、更新下载和退出修复；WPF 仅保留兼容与构建验证。

本轮已由用户确认以代码与自动化验证为准，以下专用环境验收留待后续，不作为本轮完成的前置条件。

本机完整集成测试已输出 `DESKTOP_E2E_OK`，覆盖真实 Electron／preload／Sidecar、完整状态条、桌面模式能力声明、历史与导出、备份恢复和异常恢复。该轮未启用 `CODEXU_RUN_DESKTOP_ATTACH_TEST=1`，原生桌面附着分支未执行；这些自动化结果不证明以下多屏、混合 DPI、Win+D 或 Explorer 场景已通过。

使用专用 Windows 10 22H2 / Windows 11 环境和一次性用户。记录应用提交、系统版本、安装方式、显示器数量、各屏 DPI 和工作区坐标。所有数据使用临时合成日志，恢复与清理不得指向真实用户历史。

| 场景 | 操作与验收要求 | 当前证据 |
| --- | --- | --- |
| 安装、升级、卸载 | 运行 `tools/Test-ElectronInstaller.ps1`；旧 WPF 同 AppId 原位升级，安装后启动正常，卸载保留用户数据 | 已有 CI 流程；本轮未重跑安装矩阵 |
| 首次启动和重启 | 两系统分别启动、关闭到托盘、托盘退出后重开；主窗口、设置和状态条位置可恢复 | 本机真实 Electron 合成数据测试通过；不能替代两系统矩阵 |
| 桌面模式启停与附着 | 在专用交互式 Windows 环境设置 `CODEXU_RUN_DESKTOP_ATTACH_TEST=1`，运行真实桌面测试；启用后收到附着成功事件，关闭后副本与桥接进程退出 | 能力声明和代码已恢复；本轮未运行附着分支，待验收 |
| Win+D | 启用桌面副本并打开主窗口与状态条，反复显示桌面；副本保持可见且不抢焦点，托盘及快捷键能找回主窗口 | 待专用环境验收 |
| Explorer 重启 | 仅在测试环境重启 Explorer；确认桌面副本重新附着、托盘可访问、窗口可找回、退出无残留进程 | 待专用环境验收 |
| 混合 DPI 与负坐标 | 将主窗口及状态条在 100%／150%／200% 显示器之间拖动，覆盖位于主屏左侧的负坐标屏幕；启用桌面副本，确认控件可操作、无越界及主窗口 DPI 污染 | 浏览器缩放与布局单元测试不构成原生验收；待测 |
| 移除显示器 | 在副屏放置主窗口和状态条并启用桌面副本，再断开副屏；找回位置、重启，再连接副屏；各窗口始终能回到可见工作区 | 待专用环境验收 |
| 后端与界面恢复 | 用 `node src/CodexU.Electron/scripts/test-desktop.cjs` 在临时数据目录中验证 Sidecar／renderer 崩溃恢复、历史留存、真实导出和备份恢复 | 本机完整集成测试 `DESKTOP_E2E_OK` 通过 |

每次人工验收保存操作前后截图、脱敏诊断包和通过／失败原因。失败项记录复现步骤和环境，不以自动化通过或“未复现”替代完成。
