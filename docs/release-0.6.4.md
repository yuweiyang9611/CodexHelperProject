# CodexU 0.6.4

更新模型和费率，修复新版 Codex、Claude Code 的本地用量统计，继续保留现有界面与设置。

- 内置费率目录升级至 `2026.11.1`，共 41 行：新增 GPT-6.1 Terra、GPT-6 Rosalind、Claude Haiku 5.5；Sonnet 5.5 缓存读取价自 10 月 7 日起由每百万 Token 0.20 美元降至 0.10 美元。
- 支持 Codex 新增的 `token_usage_record`，补计仅有新格式的用量，同时避免与旧 `token_count` 双写重复计算。
- Claude 同一回复的多个内容块只计一次用量，保留各工具调用及更完整的缓存写入明细。
- 升级后自动重建旧索引，在核对原日志后更新留存账本；保留截断、改写和冲突保护，无需清空历史。旧 Claude 原日志已删除且账本缺少消息 ID 时，保留原值并提示无法校正。
- 支持明确的 ChatGPT Pro 500 美元档位；仅有 `pro` 标识时使用设置中的手动月费，避免猜测套餐价格。

历史价格、自定义价格和固定目录继续保留。固定目录用户可先导出备份，再按需要恢复内置目录以使用新增费率。显示金额采用 API Standard／短上下文等效口径，不代表实际账单；Haiku 5.5 单次输入超过 100K Token 的较高档位无法从每日汇总自动推算。Claude 统计范围限于本地 Code 日志，不包含 Desktop 的全部聊天或云端 Cowork。

安装版可通过应用更新升级；便携版请使用完整 ZIP。v0.6.0／v0.6.1 若自动下载失败，请从发布页手动下载安装包并退出应用后覆盖安装。

价格来源、适用日期、兼容性范围和测试结果见 [2026-11-01 更新记录](update-2026-11-01.md)。
