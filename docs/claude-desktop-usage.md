# Claude Desktop 用量来源与限制

核对日期：2026-11-01（Asia/Tokyo），对应 0.6.5 补丁。

## 缺失原因与修复

0.6.4 的 Claude 额度入口只读取手动接入的 statusLine 快照。Desktop Code 不保证运行终端状态栏命令；仅有 `.claude/projects` 日志时，Token 可读而套餐、额度和重置时间为空。直接调用 Desktop 内嵌 CLI 的 `auth status` 也不能代表 Desktop 自身的登录状态。

本轮使用实际额度 reader 的只读探针复现了缺失，随后在 Desktop 专用缓存发现历史用量，并核对安装包内的字段映射与写入逻辑。0.6.5 增加了该来源，保留终端 statusLine 兼容，按真实采样时间整份选择来源。不会把一侧账号、另一侧窗口或旧样本缺失字段拼成一个快照。

双运行时页面原来只采用自动识别的月费，忽略用户设置。现在显式关闭对应自动推算后会采用有效的手动金额，标注“手动”及“含手动值”；读取失败仍保持未知。自动模式不会拿默认手动金额冒充已识别套餐。

## Desktop 专用历史格式

Windows 只读路径：`%LOCALAPPDATA%/Claude-Data/claude_*/plan-usage-history.json`。已验证样本来自 Desktop 4.4212.0.0 / 内嵌 Code 2.1.309。

观察到的 version 2 样本结构为 `{t, org, u}`：`t` 是 Unix 毫秒采样时间，`org` 是来源组织标识，`u.fh` 与 `u.sd` 是五小时／七天的已用百分比。`fh`／`sd` 的映射及数值单位经 Desktop 分发代码确认；缺失窗口被省略，不自动写为零。其他模型专属窗口和额外消费字段不映射到这两个环。

这是应用内部的本地缓存格式，不是公开稳定 API。实现仅读取该专用文件，不读取凭据、浏览器认证存储、聊天正文或未文档化网络接口，也不写入 Desktop 文件。组织标识仅在内存中用于一致性检查，不输出到诊断或保存为额度趋势。

- 文件上限 2 MiB，样本上限 10,000，候选安装目录上限 16；不追踪链接目录或文件。
- 只接受已验证版本及有效百分比、时间、组织字段；多组织、冲突、格式异常会拒绝自动选取。
- 读取时使用最新整条样本；缺失窗口不从旧样本补齐。读取时已超过 30 分钟或位于未来超过 5 分钟的样本会被忽略。
- 来源标为 `claude-desktop-history`，显示采样时间和非实时性质。历史快照不参与额度耗尽预测、额度提醒或状态去重，避免污染终端 statusLine 的通知。
- 显式配置 `CODEXU_CLAUDE_DIRECTORY` 时不自动读取当前用户的 Desktop 缓存，避免自定义源、其他账户或隔离测试混入本机 Desktop 数据。

## 无法从此文件获得的字段

历史缓存没有 `resets_at`、套餐名称、月付金额或活动账户认证证明。采样时间不是额度窗口起点，不能加五小时／七天作为重置时间，也不能根据历史百分比下降猜重置时间。

终端 [statusLine 官方格式](https://code.claude.com/docs/en/statusline)可提供服务端给出的 `resets_at`，但不提供订阅账单；[Desktop 官方说明](https://code.claude.com/docs/en/desktop)没有保证执行终端 statusLine。确切额度与重置时间应以 Claude 自身用量页面为准。

当前 Pro、Max、Ultra 的参考月费分别为 20、100、200 美元；Pro 也可年付，实际账单可能含税费或抵扣。旧 Max 20x 已更名 Ultra，因此旧客户端或快照的裸 `max` 标签存在歧义，不再自动推断价格；明确的 `Max 5x`、`Max 20x`、`Ultra` 标签仍可给出参考价。[官方价格](https://claude.com/pricing)、[Ultra 说明](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan)

## 验证

回归覆盖实际 reader 缺少状态栏时读取 Desktop、来源新旧选择、缺失窗口、零值、组织冲突、时间与文件大小边界，以及手动月费响应更新。实机只读探针已确认两组百分比来自 Desktop 历史，账号和重置时间保持未知。测试只使用构造样本，不包含真实组织标识、用户用量或账单数据。

本地验证：708 项 .NET 测试、220 项 Web 单元测试通过；Playwright 44 个适用用例通过，其余 106 个按配置跳过。新增 Desktop 场景覆盖两个视图的采样时间、缺失重置时间和手动月费，并人工核对三张构造数据截图。两张双运行时旧基线因来源文字与说明行变化更新后复跑通过。严格 Release 编译零警告、零错误；格式、版本一致性、发布保护和隐私检查通过。远端 CI 与 Release 继续按最终提交执行完整打包和安装验证。
